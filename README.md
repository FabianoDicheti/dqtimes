# DQTimes - Frontend React

Sistema de Previsão de Séries Temporais - Interface React

## 🚀 Início Rápido

### Pré-requisitos

- Node.js 16+ e npm (ou yarn)

### Instalação

```bash
# Instalar dependências
npm install

# Iniciar servidor de desenvolvimento
npm start
```

O aplicativo estará disponível em `http://localhost:3000`
